# Sudoku

Полноценное веб-приложение судоку с поддержкой генерации заданий, сохранений и статистики. Используется Java 17, Maven, SQLite и Flyway.

## Быстрый старт

1. Убедитесь, что установлен JDK 17+ и Maven.
2. Перейдите в папку проекта: `cd sudoku`.
3. Выполните миграции и юнит-тесты: `mvn test`.
4. Запустите приложение: `mvn jetty:run` и откройте `http://localhost:8080`.

База `sudoku.db` создаётся автоматически рядом с приложением, миграции Flyway применяются при старте.

## Возможности

- Генерация новых задач трёх уровней сложности (EASY, MEDIUM, HARD) с гарантированно единственным решением.
- Проверка корректности ходов и автоматическое решение головоломки на сервере.
- Сохранения прогресса с фиксацией предзаполненных ячеек и времени игры.
- История игр и сводная статистика (количество игр, среднее и лучшее время, разбивка по уровням).

## API

- `GET /api/new?level=EASY|MEDIUM|HARD` — создать новую игру, вернуть seed и ID.
- `POST /api/solve` — решить доску (`{ "seed": "..." }` или `{ "puzzleId": 1 }`).
- `POST /api/validate-move` — проверить ход (`seed`, `row`, `col`, `value`).
- `POST /api/savegame` — сохранить игру (`puzzleId`, `boardSnapshot`, `presetSnapshot`, `elapsedSeconds`).
- `GET /api/savegame` — список сохранений; `GET /api/savegame/{id}` — загрузить конкретное.
- `DELETE /api/savegame/{id}` — удалить сохранение.
- `GET /api/stats` — получить статистику; `POST /api/stats` — сохранить результат игры.

UI на JSP/JavaScript использует эти эндпоинты напрямую, поэтому достаточно запустить Jetty.
